\begin{abstract}
Reservoir computing provides a controlled setting for studying how recurrent network architecture shapes computation: input signals are projected into a high-dimensional state space by a fixed nonlinear dynamical system, and only the readout is trained. However, reservoir performance can be strongly dependent on hyperparameters such as spectral radius, input scaling, leak rate, and bias. This paper asks which recurrent-network features support invariance to those parameter changes. We use the \textit{C.\ elegans} chemical-synapse connectome as a structured, biologically grounded reservoir architecture and measure computational capability with four task-agnostic metrics---memory capacity (MC), truncated single-delay information-processing capacity (IPC), kernel rank (KR), and generalization rank (GR). Hyperparameter invariance is quantified as the coefficient of variation of these metrics across sweeps of spectral radius, input scaling, leak rate, and neuron bias.

To examine architectural contributors to invariance, we construct controlled perturbations that modify connectivity topology, weight-magnitude distributions, magnitude placement, and excitatory/inhibitory sign structure while preserving selected complementary properties. Across these experiments, the ambiguous-edge \textit{C.\ elegans} connectome consistently occupies a relatively low-variance regime.

The central result is a performance--invariance tradeoff: perturbations that raise task-agnostic computational capacity tend to make those capacities more dependent on reservoir hyperparameters. Across both sign-balance and shuffle controls, this tradeoff is closely tied to the raw spectral radius before normalization. Perturbations that lower the raw spectral radius are rescaled more strongly to the target radius and tend to increase both performance and CV, whereas perturbations that raise the raw spectral radius tend to decrease both. Thus, the connectome-derived chemical sign structure is not interpreted as an optimum for reservoir performance; instead, it identifies a structured recurrent regime in which topology, sign placement, and weight placement are associated with hyperparameter sensitivity, in part through the pre-normalization spectral radius.
\end{abstract}

\begin{highlights}
\item Connectome-derived reservoir architectures can occupy low hyperparameter-sensitivity regimes.
\item Higher task-agnostic capacity often coincides with higher sensitivity to reservoir hyperparameters.
\item Raw spectral radius before normalization is an important mediator of architecture-dependent performance--invariance tradeoffs.
\end{highlights}

\section{Introduction}
Reservoir computing uses a fixed recurrent dynamical system to project input sequences into a high-dimensional state space, after which only a readout is trained \parencite{jaeger_echo_state_2001,maass_lsm_2002}. This separation between fixed recurrent weights and trained readouts makes reservoir models useful for studying how recurrent neural network architecture shapes computation. At the same time, reservoir dynamics and performance can vary strongly with hyperparameters such as spectral radius, input scaling, leak rate, and neuronal bias \parencite{Lukosevicius2012PracticalESN,Matzner2022HyperparameterTuningESN}.

Most reservoir-computing theory and practice treats random recurrent networks as a strong generic baseline because they can provide diverse, weakly correlated nonlinear features and be tuned to dynamical regimes that support memory and separability \parencite{Lukosevicius2012PracticalESN}. This motivates a complementary comparison with architectures that were not designed as random feature maps. Biological connectomes provide such cases because their wiring is non-random, sparse, directed, weighted, and constrained by biological function. The \textit{C.\ elegans} connectome is a useful example because it is compact, well characterized, and experimentally grounded.

This motivates a question that is central to neural-network architecture design but distinct from peak-performance optimization: which structural properties make reservoir statistics stable across hyperparameter variation?

Biologically inspired networks have also been used directly as reservoirs or reservoir-like substrates. Studies have treated biological connectivity as a fixed graph: Kawai and colleagues compared echo-state networks with small-world structure to models based on human cortical connectivity, while Morra and Daley replaced the reservoir layer of an ESN with fruit-fly connectome-derived topologies \parencite{KAWAI201915,morra_daley_2022}. Later work using the fruit-fly lateral horn found that connectome-based reservoirs supported multifunctionality across a broader region of \([\rho,\gamma]\)-space than Erd\H{o}s--R\'enyi controls \parencite{morra_fly_rc_2023}. Other work has moved from anatomical graphs to living substrates, using cultured cortical neurons as the reservoir itself \parencite{iannello_brc_2025}. Together, these studies show that biological reservoir computing spans multiple levels of biological realism, from abstract connectivity patterns inspired by nervous systems to living neuronal substrates.

We use the ambiguous-edge version of an anatomical \textit{C.\ elegans} chemical-synapse connectome as a structured recurrent weight matrix, then apply controlled perturbations that isolate topology, inferred excitatory/inhibitory sign structure, weight-magnitude distribution, magnitude placement, and sign placement. Throughout this paper, E/I balance refers to the ratio or fraction of excitatory to inhibitory synaptic signs in the modeled reservoir; it is an edge-level quantity, not a count of excitatory or inhibitory neurons. Reservoir behavior is evaluated with task-agnostic metrics, and hyperparameter invariance is quantified across sweeps of spectral radius, input scaling, leak rate, and neuron-bias range.

The results identify a tradeoff between performance and hyperparameter invariance. Perturbations that enhance computational performance often also increase sensitivity to hyperparameter choice, and the strongest effects appear to act through the raw spectral radius before normalization. The contribution of this study is to separate global E/I sign ratio, local sign placement, topology, and weight placement in controlled connectome-derived reservoir ablations, and to test whether their effects on task-agnostic performance and hyperparameter invariance persist when spectral-radius normalization is held fixed.
\section{Methods}
\label{sec:methods}
\subsection{Reservoir model and hyperparameters}
We use echo state networks, a discrete-time reservoir-computing model in which recurrent weights are fixed and only linear readouts are trained using linear regression \parencite{jaeger_echo_state_2001,Lukosevicius2012PracticalESN}. The state update is
\begin{align}
\tilde{x}_{t+1} &= \tanh\!\left(W^{\mathrm{res}} x_t + s_{\mathrm{in}}W^{\mathrm{in}} u_{t+1} + b \right), \\
x_{t+1} &= (1-\alpha)\,x_t + \alpha\,\tilde{x}_{t+1}, \\
y_t &= W^{\mathrm{out}}\,x_t.
\end{align}
Here \(t\) is the discrete time index; \(N\) is the number of reservoir units; \(x_t,\tilde{x}_{t+1}\in\mathbb{R}^{N}\) are the states after and before leaky integration, respectively; and \(u_t\in\mathbb{R}^{m}\) and \(y_t\in\mathbb{R}^{p}\) are the input and linear readout. The experiments use scalar inputs, so \(m=1\). The matrices \(W^{\mathrm{res}}\in\mathbb{R}^{N\times N}\), \(W^{\mathrm{in}}\in\mathbb{R}^{N\times m}\), and \(W^{\mathrm{out}}\in\mathbb{R}^{p\times N}\) are the recurrent, input, and readout weight matrices, respectively. The scalar \(s_{\mathrm{in}}\) sets the input scale, \(b\in\mathbb{R}^{N}\) is a fixed per-neuron bias vector, and \(\alpha\in(0,1]\) is the leak rate. The \(\tanh\) activation is applied elementwise.\footnote{The readout dimension is \(p=5\) for IPC so that multiple polynomial orders can be solved in a single batch; otherwise \(p=1\).} Only \(W^{\mathrm{out}}\) is trained, and each instantiated reservoir is rescaled to a target spectral radius before evaluation.

\label{sec:hyperparameters}
The experiments sweep four hyperparameters: spectral radius, leak rate, input scaling, and neuron-bias. The spectral radius \(\rho(W^{\mathrm{res}})\) roughly sets the strength of recurrent feedback, where
\[
\rho(W) = \max_{1 \le i \le N} |\lambda_i|.
\]
Here \(W\in\mathbb{R}^{N\times N}\) is a square weight matrix and \(\lambda_i\) is its \(i\)th eigenvalue. In reservoir computing, recurrent matrices are commonly rescaled to a target spectral radius near one to keep the dynamics in a useful operating range\parencite{jaeger_echo_state_2001,Lukosevicius2012PracticalESN}.\footnote{Reservoirs can remain computationally useful for values below or above this range \parencite{gallicchio_chasing_2019}.} In our experiments, we apply network perturbations and then rescale the resulting matrix as
\[
W^{\mathrm{res}}
=
\frac{\rho_{\mathrm{target}}}{\rho(W')}W',
\qquad
\rho(W')=\max_i |\lambda_i(W')|.
\]
Here \(W'\) is the recurrent matrix after all perturbations, \(\lambda_i(W')\) is its \(i\)th eigenvalue, \(\rho(W')\) is its spectral radius before normalization, \(\rho_{\mathrm{target}}\) is the selected target spectral radius, and \(W^{\mathrm{res}}\) is the normalized recurrent matrix used in the state update.

For the remaining hyperparameters, the leak rate \(\alpha\) sets the effective timescale of the reservoir, and input scaling \(s_{\mathrm{in}}\) sets the external drive. The neuron-bias parameter \(\beta\) controls the fixed term \(b\) in the state update:
\[
b_i\sim \mathcal{U}(-\beta,\beta), \qquad i\in\{1,\ldots,N\}.
\]
Here \(b_i\) is the bias assigned to reservoir unit \(i\), \(\beta\geq0\) sets the maximum absolute bias, and \(\mathcal{U}(a,b)\) denotes the continuous uniform distribution on the interval \([a,b]\). Each \(b_i\) is drawn independently and held fixed for that reservoir instantiation.

The sweep values were chosen as a compact sensitivity grid. Every architecture is evaluated on the same grid. The spectral-radius values \(\{0.6,0.8,0.95,1.05\}\) bracket the standard near-one operating regime while including more contractive and slightly supercritical targets \parencite{Lukosevicius2012PracticalESN,gallicchio_chasing_2019}. The leak values \(\{0.6,0.8,1.0\}\) sample moderate leaky integration through the non-leaky update, the input-scaling values \(\{0.1,0.5,1.0,1.5\}\) span weak to strong input drive, and the bias values \(\{0.0,0.1\}\) compare an unbiased reservoir with a small fixed per-neuron offset. These choices cover standard ESN design knobs, including bias terms that can affect reservoir performance \parencite{Lukosevicius2012PracticalESN,platt_systematic_2022,Matzner2022HyperparameterTuningESN}. Their Cartesian product contains \(4\times3\times4\times2=96\) hyperparameter combinations. For each trial and task-agnostic metric, these combinations produce 96 metric values. We average those values to obtain mean performance and use their mean and standard deviation to calculate one trial's CV.

\subsection{Connectome data and preprocessing}
\label{sec:connectome_dataset}
We use an anatomical \textit{C.\ elegans} chemical-synapse connectome with predicted chemical polarity labels derived from EleganSign \parencite{fenyves_szilágyi_zsolt_vassy_csaba_2020,elegansign_web}. Here, a polarity label specifies whether a chemical connection is predicted to have an excitatory (positive) or inhibitory (negative) effect. In our reservoir model, each neuron in the connectome is represented as one reservoir unit, and the directed chemical synapses define the recurrent matrix \(W^{\mathrm{res}}\). A chemical connection from neuron \(i\) to neuron \(j\) adds a directed edge with magnitude equal to the number of synaptic contacts from \(i\) to neuron \(j\) \parencite{Varshney2011,Cook2019,Casal2020,churchland_garcia-ojalvo_2026}. Self-loops, for which \(i=j\), are removed during preprocessing. For chemical edges with a predicted polarity label, we multiply this contact-count magnitude by the inferred sign, so predicted excitatory chemical synapses enter the matrix with positive weights and predicted inhibitory chemical synapses enter with negative weights. Ambiguous (unpredicted/complex) chemical edges are handled by the preprocessing versions described below. The resulting signed, weighted adjacency matrix is the fixed recurrent reservoir used in the reservoir update above: inputs drive the reservoir through \(W^{\mathrm{in}}\), recurrent activity propagates through the connectome-derived \(W^{\mathrm{res}}\), and only the output readout \(W^{\mathrm{out}}\) is trained. Before evaluation, each reservoir instance is rescaled to the target spectral radius described in ~\ref{sec:hyperparameters}.

These polarity labels apply only to chemical synapses. We follow the EleganSign chemical-edge export as the source database for the recurrent matrix. EleganSign predicts excitatory or inhibitory effects for chemical synapses, so its database does not include electrical synapses. The labels are also predictions rather than direct functional measurements, because they are inferred from gene-expression and neurotransmitter logic rather than from voltage- or calcium-response measurements. EleganSign predicts signs for 1740 synapses, while 1864 synapses have unknown or complex sign predictions. To make the analysis less dependent on a single treatment of these ambiguous edges, we construct two reservoir versions. In the predicted-polarity-only version, unknown or complex-sign connections are removed. In the ambiguous-edge version, the 1864 ambiguous edges are retained. For each repeat, these edges are randomly permuted, exactly 452 are assigned negative signs, and the remaining 1412 are assigned positive signs. This fixed count matches the negative fraction among non-ambiguous connections, \(p_-=0.2425287356\). The main results use the ambiguous-edge version, while selected experiments include the predicted-polarity-only version.

\subsection{Task-agnostic reservoir metrics}
We measure four task-agnostic reservoir metrics: kernel rank (KR), generalization rank (GR), memory capacity (MC), and a truncated single-delay information-processing-capacity (IPC) diagnostic \parencite{maass_comp_power_2004,Jaeger2002STMESN,dambre_ipc_2012,pilati_ceni_michieletti_gallicchio_ricciardi_milano_2026}.

\subsubsection{Kernel Rank}
Kernel rank (KR) measures how many effectively independent reservoir activity dimensions are produced by the input drive \parencite{maass_comp_power_2004}. After discarding an initial washout period to remove dependence on the arbitrary initial state, we collect the remaining reservoir states in the post-washout state matrix \(X\in\mathbb{R}^{T\times N}\), center it over time, compute singular values \(S=\{\sigma_i\}\), normalize them as \(p_i=\sigma_i/\sum_j\sigma_j\), and compute effective rank ($\mathrm{erank}$):
\[
\mathrm{KR} = \mathrm{erank}
=
\exp\left(-\sum_i p_i\ln p_i\right).
\]

\subsubsection{Generalization Rank}
Generalization rank (GR) measures how reservoir states change under small input perturbations \parencite{maass_comp_power_2004}. Let \(u_t\sim\mathcal{U}(-1,1)\) be the clean input and \(u'_t=u_t+\kappa\varepsilon_t\), where \(\varepsilon_t\sim\mathcal{N}(0,1)\) and \(\kappa=0.01\). If \(X\) and \(X'\) are the corresponding post-washout state matrices, then
\[
\mathrm{GR}
=
\mathrm{erank}(X'-X).
\]

\subsubsection{Memory Capacity}
Memory capacity (MC) measures how well a linear readout can reconstruct past inputs from the current reservoir state. For each delay \(d\), a ridge-regression readout is trained to predict \(u(t-d)\) from \(x(t)\), and the squared Pearson correlation between predicted and true delayed input is recorded. Here, \(r_{\mathrm{score}}\) denotes this squared Pearson correlation, bounded between 0 and 1 \parencite{Jaeger2002STMESN}; its full definition is given in Supplemental Section~\ref{supp:r_score}. We approximate the total memory capacity by summing over delays up to \(D_{\max}=30\):
\[
\mathrm{MC}
=
\sum_{d=1}^{D_{\max}}
r_{\mathrm{score}}(u(t-d),\hat{u}_d(t)).
\]
The sensitivity of MC to this delay truncation is reported in Supplemental Section~\ref{supp:metric_truncation}.

\subsubsection{Truncated information-processing-capacity diagnostic}
\label{sec:ipc}
Information processing capacity (IPC) measures how well the reservoir can reconstruct nonlinear functions of delayed inputs \parencite{dambre_ipc_2012}. Here, IPC denotes a truncated single-delay diagnostic rather than the full IPC. Specifically, we evaluate univariate Legendre polynomial targets of one delayed input at a time and omit pairwise and higher-order cross-delay product terms. This still measures the reservoir's ability to generate nonlinear transformations of input history, but it does not estimate the full capacity over all nonlinear input combinations. For Legendre polynomial orders \(K=\{1,2,3,4,5\}\) and delays \(d\in\{1,\ldots,D_{\max}\}\), with \(D_{\max}=30\), let \(z_{k,d}(t)=P_k(u(t-d))\). We compute
\[
\mathrm{IPC}
=
\sum_{d=1}^{D_{\max}}
\sum_{k\in K}
\max\!\left(0,\,
r_{\mathrm{score}}\!\left(z_{k,d}(t),\hat{z}_{k,d}(t)\right)
\right).
\]
Because cross-delay products are not included, the reported IPC values should be interpreted as an incomplete IPC-style statistic rather than an exhaustive estimate of full IPC. Sensitivity to the selected polynomial orders and maximum delay is reported in Supplemental Section~\ref{supp:metric_truncation}.

\subsection{Hyperparameter-invariance metric}
To investigate stability under hyperparameter variation, we examine how each performance metric changes across the hyperparameter grid.
We quantify hyperparameter invariance with the coefficient of variation (CV):
\[CV = \frac{\text{std}(a)}{\bar{a}}\]
where \(a\) is the set of values for a given task-agnostic performance metric across all evaluated hyperparameter settings within a trial. CV is a measure of relative dispersion, which makes it useful for comparing variability across models with different performance scales.
In reservoir computing, hyperparameter sensitivity is commonly analyzed through area-under-curve, performance curves, or robustness intervals rather than through a single standard statistic \parencite{KAWAI201915,jaurigue_timescale_2023,freddi_robust_spiking_2026,srinivasan_ei_balance_2025}. Our use of CV compresses sensitivity into one value per metric: low CV indicates that a metric remains stable across spectral radius, leak rate, input scaling, and neuron bias, whereas high CV indicates stronger dependence on hyperparameter choice.


\subsection{Structural perturbations and architecture controls}
To determine which topological and weight-related features influence robustness, we construct controlled network perturbations derived from the \emph{C.~elegans} connectome. Table~\ref{tab:architecture_groups} summarizes the architecture families used in the ablations; full architecture definitions and visualizations are provided in Supplemental Section~\ref{supp:architectures}. Figures~\ref{fig:shuffle_four_panel}, \ref{fig:a_to_h}, and \ref{fig:i_to_o} show graphical representations of the network perturbations and architecture controls used in this work.

Raw spectral radius is not held fixed by these constructions; its variation is an outcome of the structural manipulations and is analyzed explicitly below.

\subsubsection{Connection shuffle}
\label{Connection-Shuffle}
We define a connection shuffle as a directed degree-preserving edge swap. Let \(W\) be the weighted adjacency matrix. We randomly select two existing directed edges \((a,b)\) and \((c,d)\), where \(a,b,c,d\) are distinct and the proposed edges \((a,d)\) and \((c,b)\) do not already exist. We then form a new matrix \(W'\) by setting
\[
W'_{ad}=W_{ab}, \qquad
W'_{cb}=W_{cd}, \qquad
W'_{ab}=0, \qquad
W'_{cd}=0,
\]
with all other entries unchanged. This preserves each node's in-degree and out-degree while shuffling the neighborhood structure.
\subsubsection{Weight shuffle}

\label{Weight-Shuffle}
Fix the synaptic connectivity pattern and randomly permute the weights assigned to existing connections. Let
\[
NZ=\{(i,j): W_{ij}\neq 0\}
\]
denote the set of nonzero entries in the weight matrix. We extract the corresponding weights into a vector,
\[
w_{NZ}=\{W_{ij}:(i,j)\in NZ\},
\]
shuffle this vector, and then reassign the shuffled weights back to the same nonzero indices. Thus, the set of existing connections is unchanged, but the weights assigned to those connections are redistributed across the fixed network topology.

\section{Results}
\label{sec:results}
The experiments are organized as a sequence of architecture ablations around the connectome-derived reservoir. The main results use the ambiguous-edge version of the \textit{C.\ elegans} reservoir, in which predicted-polarity chemical edges retain their EleganSign labels and ambiguous chemical edges are randomly permuted and assigned fixed counts of 452 negative and 1412 positive signs. We first compare this reservoir against random-topology, binary-weight, and sign-preserving controls. We then isolate the global E/I ratio by sweeping the fraction of negative edges in the ambiguous-edge connectome, the predicted-polarity-only connectome, and a matched Erd\H{o}s--R\'enyi topology. Next, we test the contribution of spectral-radius normalization to the sign-sweep effects by comparing own-radius scaling with scaling by the original matrix radius. Finally, we use degree-preserving connection, sign, and weight shuffles to distinguish the effects of topology, local sign placement, and contact-count magnitude placement.

\subsection{The ambiguous-edge connectome occupies a low-variance reservoir regime}
Figure~\ref{fig:arch} compares architecture families by mean task-agnostic performance and hyperparameter CV. Each panel shows one metric: GR, truncated IPC, KR, or MC. The vertical axis gives the mean metric value across trials, and the horizontal axis gives the coefficient of variation across the spectral-radius, leak-rate, input-scaling, and neuron-bias sweep. Contours show the 50\% density region for each architecture family, and markers show the corresponding condition means. Color indicates the percentage of edges with negative weights. The 50\% negative-edge models, shown in yellow, appear at higher mean performance and higher CV. Models at the ambiguous-edge connectome's negative-edge fraction, shown in purple, appear at lower mean performance and lower CV. The all-positive binary-weight model, shown in blue at 0\% negative edges, appears in the low-performance, low-CV region. These comparisons motivate the central claim tested in the following sections: global E/I sign imbalance appears to contribute strongly to the connectome's low-variance behavior under the present topology and magnitude regimes, while sign placement and weight magnitudes have smaller, yet non-negligible effects.

\subsection{Global sign-balance sweep reveals a performance--invariance tradeoff}
\label{balance}
To isolate global sign balance, we randomly flipped synapse signs while leaving the connectivity pattern and weight magnitudes fixed. This changes the fraction of negative edges in the recurrent matrix without assigning neurons to excitatory or inhibitory classes.\footnote{Because signs are reassigned independently, this sweep changes both the global sign fraction and local sign placement. The sign-preserving controls in Figure~\ref{fig:arch} and Supplemental Section~\ref{supp:sign_norm_controls} quantify the smaller contribution of sign placement.} For each negative-edge fraction, we computed the mean value and hyperparameter CV of the four task-agnostic metrics.

Figure~\ref{fig:ambig_cel_frac_curves} shows these sign-fraction sweeps for the ambiguous-edge \textit{C.\ elegans} reservoir. The horizontal axes give the percentage of negative edges and mean CV, the vertical axis shows mean performance. \subsection{Spectral radius as an important mediator of the performance--invariance tradeoff}
\label{sec:raw_rho_summary}
The sign-normalization and shuffle results support a common spectral-radius pathway: structural perturbations change the raw spectral radius before spectral-radius normalization, which changes the scale of $W$ after normalization. Figure~\ref{fig:raw_rho_summary} summarizes this relationship across the sign-fraction sweeps and the shuffle controls. Across metrics, lower \(\rho_{\mathrm{raw}}\) coincides with higher mean performance and higher CV, while higher \(\rho_{\mathrm{raw}}\) is associated with lower performance and lower CV. The plotted families show that the same direction appears in multiple experimental settings: balanced sign sweeps, signed-unit controls, binary topology controls, and real-weight shuffles.

Thus, the synthesis is not simply that the global E/I ratio matters. A purely sign-balance explanation would predict that controls with the same negative-edge fraction should behave similarly. Instead, the shuffle and normalization experiments show that topology, local sign placement, weight-magnitude distribution and placement can move reservoirs with the same global sign ratio into different performance--CV regimes. Together, the controls are consistent with raw spectral radius as an important, but not exclusive, pathway linking these structural factors to reservoir dynamics.

\section{Discussion}
This study uses a connectome-derived reservoir as a structured recurrent neural network model for asking how architecture controls hyperparameter sensitivity. The ambiguous-edge \textit{C.\ elegans} connectome occupies a relatively low-variance reservoir regime. The ablations reveal a hierarchy of interacting architectural effects. Global E/I sign imbalance is the strongest control identified in the present model: preserving the chemical sign ratio recovers much of the connectome's invariance across task-agnostic metrics, even when exact sign placement or edge magnitudes are altered. Its influence nevertheless depends on topology, sign placement, and the distribution and placement of weight magnitudes. E/I balance therefore acts as an architecture-dependent parameter rather than an independent determinant of reservoir dynamics.


Figure~\ref{fig:arch} demonstrates that the ambiguous-edge \textit{C.\ elegans} model has the lowest mean CV for all metrics except MC. Furthermore, weight shuffling, connection shuffling, and connection-plus-weight shuffling all move the reservoir toward higher mean performance and higher CV (Figure~\ref{fig:shuf_all}, top row). Thus, in this reservoir abstraction, the local topology, sign and weight placement of the ambiguous-edge \textit{C.\ elegans} model appear to favor invariance over peak performance.

The sign-fraction sweeps show the core performance--invariance tradeoff. Figures~\ref{fig:arch},~\ref{fig:er_frac_curves} and~\ref{fig:og_cel_frac_curves} show that moving from strongly sign-imbalanced networks toward more balanced edge signs generally increases mean task-agnostic performance, but also increases CV. The same qualitative trend appears in the ambiguous-edge \textit{C.\ elegans} graph, the \textit{C.\ elegans}-matched ER topology, and the predicted-polarity-only \textit{C.\ elegans} magnitude pattern. Under the present modeling choices, the ambiguous-edge \textit{C.\ elegans} instantiation therefore lies on the low-variance side of this curve rather than near the peak-performance region. The sign imbalance estimated from the labeled EleganSign connections does not prioritize peak reservoir performance in this abstraction; instead, it helps produce a more hyperparameter-invariant, lower-performance operating point.

The sign-normalization ablations test this proposed pathway by comparing the usual own-radius normalization, \(W/\rho(W)\), with normalization by the original matrix's spectral radius, \(W/\rho(W_{\mathrm{orig}})\). Under own-radius normalization, performance increases strongly as the negative-edge fraction moves toward the balanced regime, and CV increases at the same time (Figure~\ref{fig:sign_norm_matched_cel}). When the same perturbed matrices are instead scaled by the original spectral radius, the performance curves are much flatter through the middle of the sign-fraction sweep. The ER-matched and predicted-polarity-only controls show the same qualitative separation between normalization conventions (Supplemental Figures~\ref{fig:sign_norm_matched_er} and~\ref{fig:sign_norm_removed_cel}). In these sweeps, more balanced signs are associated with lower \(\rho_{\mathrm{raw}}\), and own-radius normalization then produces larger effective recurrent weight magnitudes. The data are therefore consistent with this rescaling pathway contributing to higher task-agnostic performance and greater hyperparameter sensitivity. Consistent with this interpretation, the sign-balanced reservoir exhibits more active neuron--time samples and more activation-threshold crossings than the all-positive reservoir (Supplemental Figure~\ref{fig:activity_0_vs_50}). The mean absolute normalized weight within closed three-neuron subgraphs also increases toward the middle of the sign-fraction sweep (Supplemental Figure~\ref{fig:triad_sign_fraction}). Because topology and unnormalized magnitudes are fixed, the triad demonstrates a higher recurrent weight scale at balanced sign fractions.

This interpretation also connects the present results to recent reservoir work on the no-strong-loops principle. Hadaeghi and colleagues show that stronger reciprocal loops inflate \(\rho(W)\), forcing spectral-radius normalization to downscale recurrent weights more strongly and reducing memory capacity and kernel rank \parencite{hadaeghi_no_strong_loops_2025}.

Topology, sign placement, and weight placement have detectable effects when all ablations are scaled by the fixed spectral radius of their row baseline, but these effects are amplified when each ablation is normalized by its updated spectral radius. The fixed-baseline-radius control (Supplemental Figure~\ref{fig:shuf_all_supp}) therefore shows that the shuffle effects are not solely consequences of normalization; the stronger separation under own-radius normalization (Figure~\ref{fig:shuf_all}) is consistent with the spectral-radius account developed above.

The sign-balance result explains the main architecture-level separation, but it does not explain differences among controls that share the same global sign ratio. The degree-preserving shuffle experiments reveal residual differences: controls with lower \(\rho_{\mathrm{raw}}\) tend to move toward higher mean performance and higher CV, whereas controls with higher \(\rho_{\mathrm{raw}}\) tend to move in the opposite direction (Figure~\ref{fig:shuf_all}).

Direct biological interpretation should be cautious because the connectome model compresses substantial uncertainty into a static network with predicted chemical polarity labels. The main analyses use the ambiguous-edge version of the \textit{C.\ elegans} reservoir. Predicted-polarity chemical edges retain their EleganSign-derived labels, but those labels are inferred rather than directly measured: they come from gene-expression and neurotransmitter logic, not from voltage- or calcium-response measurements \parencite{fenyves_szilágyi_zsolt_vassy_csaba_2020,elegansign_web}. The model includes chemical synapses only and omits electrical synapses, making it a less complete representation of the biological circuit. Coverage is incomplete as well: many chemical synapses have complex or unpredicted labels, and the inferred inhibitory edge fraction depends on how those ambiguous cases are handled. Furthermore, \textit{C.\ elegans} E/I balance varies across development and aging \parencite{wirak_florman_alkema_connor_gabel_2022,tanis_bellemer_moresco_forbush_koelle_2009}, and our model delivers inputs to all neurons rather than to biologically separated populations, such as sending inputs to sensory neurons and taking outputs from motor neurons or muscles. Thus, this work should be read as a structural reservoir analysis, not a faithful dynamical simulation of the animal.

The shape of the sign-balance curves should also be interpreted through the reservoir abstraction. The state nonlinearity is \(\tanh\), which is odd-symmetric, and the readout is linear. Under these choices, exchanging positive recurrent weights for negative recurrent weights changes the sign structure of the recurrent drive, but the linear readout can absorb corresponding sign changes in the state features. This makes the sign-flip experiment approximately symmetric by construction.

This helps explain why the present curves differ from studies in which the best operating point is slightly inhibition-dominated. Srinivasan, Plenz, and Girvan as well as de Graaf and colleagues report performance benefits from balanced or slightly inhibition-dominated adaptive E/I regimes \parencite{srinivasan_ei_balance_2025,de_graaf_spinal_inhibition_2025}. We hypothesize that the difference may partly reflect the activation functions used across these models: Srinivasan, Plenz, and Girvan use a sigmoid activation, whereas de Graaf and colleagues use a rectified \(\tanh\) activation. In such models, the activation function is not fully sign-symmetric. Positive and negative inputs are transformed differently, so the optimal E/I ratio can shift away from exactly 50:50.



For reservoir computing and recurrent neural network design, raw spectral radius should therefore be treated as an important mediator between architecture and performance--invariance behavior, but not as its sole determinant. Several directions follow.

First, the same framework could be used to investigate how recurrent-network optimization algorithms alter task-agnostic statistics, and whether task-driven optimization moves structured reservoirs along the same performance--invariance axes identified here. Relevant comparisons include reward-modulated reinforcement learning in densely recurrent biological networks \parencite{churchland_garcia-ojalvo_2026}, covariance-matrix-adaptation evolution strategies (CMA-ES) \parencite{hansen_cmaes_2016}, and scalable, derivative-free evolution strategies such as OpenAI-ES \parencite{salimans_evolution_2017}.

Second, future experiments should use anatomically motivated input and output populations rather than driving and reading out from every neuron. Restricting inputs to sensory neurons and defining outputs over motor neurons or muscles would make the reservoir task more closely reflect the flow of information through the \textit{C.\ elegans} circuit, while enabling more direct comparison with previous connectome-based computational models \parencite{KAWAI201915,yu_bpu_2025}.

Third, the uncertainty in synaptic-sign assignment should be treated as an experimental variable in its own right. Comparing alternative neurotransmitter-to-sign mappings, and systematically varying the treatment of ambiguous edges, would reveal whether the observed E/I-balance effects persist across plausible inhibitory fractions and polarity assumptions.

Fourth, repeating the analyses with full information-processing-capacity (IPC) measurements would provide a more complete account of the reservoirs' computational properties. This was not feasible for the present ablation grid because of its computational cost.

Fifth, future work should test whether the performance--invariance profiles of sign-balanced networks can be reproduced through changes in topology and weight magnitudes alone.

\subsection{Squared-correlation score}
\label{supp:r_score}
For target values \(y_t\) and predictions \(\hat{y}_t\) over evaluation samples indexed by \(t\), the score used for MC and the truncated IPC diagnostic is
\[
r_{\mathrm{score}}(y,\hat{y})
=
\operatorname{clip}_{[0,1]}\!\left[
\left(
\frac{\sum_t (y_t-\bar{y})(\hat{y}_t-\bar{\hat{y}})}
{\sqrt{\sum_t (y_t-\bar{y})^2\sum_t (\hat{y}_t-\bar{\hat{y}})^2}+\epsilon}
\right)^2
\right].
\]
Here, \(\bar{y}\) and \(\bar{\hat{y}}\) are the sample means of the target and predicted values, respectively; \(\epsilon=10^{-12}\) prevents division by zero; and \(\operatorname{clip}_{[0,1]}\) restricts numerical output to the interval from 0 to 1. Thus, \(r_{\mathrm{score}}\) is the squared Pearson correlation.

\subsection{Truncation sensitivity of MC and IPC}
\label{supp:metric_truncation}
We tested whether the choices \(D_{\max}=30\) and \(K=\{1,2,3,4,5\}\) materially affect comparisons among the ten architecture models. For these checks, capture denotes the truncated capacity as a percentage of the corresponding value from an extended reference calculation, and ranking stability is calculated across architecture-level means.

For the polynomial-order check, the sum over orders 1--5 captured \(92.82\%\pm2.34\%\) of the value obtained using orders 1--10; the minimum capture was \(82.37\%\), and the fifth percentile was \(88.81\%\). Agreement between the two calculations was high (Pearson \(r=0.9993\), Spearman \(r_s=0.9979\)).
For the IPC delay check, values computed with \(D_{\max}=30\) captured \(91.10\%\)--\(96.33\%\) of the corresponding \(D_{\max}=80\) architecture means. For the ambiguous-edge \textit{C.\ elegans} model, capture was \(92.16\%\pm1.22\%\). Despite the reduction in absolute IPC, the ranking of all ten architectures was unchanged relative to \(D_{\max}=80\) (Pearson \(r=1.0000\), Spearman \(r_s=1.0000\)).

MC was less sensitive to the delay cutoff. At \(D_{\max}=30\), the mean capture across architectures was \(97.86\%\), with architecture means ranging from \(96.90\%\) to \(98.89\%\). Capture for the ambiguous-edge \textit{C.\ elegans} model was \(97.18\%\pm0.66\%\), and the architecture ranking was again identical to that obtained with \(D_{\max}=80\) (Pearson \(r=1.0000\), Spearman \(r_s=1.0000\)). Thus, the selected truncations modestly reduce absolute capacity values, particularly for IPC, but preserve the comparative architecture results.

\subsection{Additional sign-normalization controls}
\label{supp:sign_norm_controls}
The main text shows the sign-normalization ablation for the ambiguous-edge \textit{C.\ elegans} graph. The same normalization comparison was repeated for the matched ER topology and the predicted-polarity-only \textit{C.\ elegans} magnitude pattern.

The flattening observed under original-radius scaling is expected only over the range of sign fractions where the perturbed matrix has a lower raw spectral radius than the original matrix. Let \(q\) denote the negative-edge fraction and \(q_{\mathrm{orig}}\) the original fraction. For the sign-sweep experiments, this middle region is approximately the interval between \(q_{\mathrm{orig}}\) and its sign complement, \(1-q_{\mathrm{orig}}\). In that range, \(\rho(W)<\rho(W_{\mathrm{orig}})\), so original-radius scaling gives a post-scaling radius
\[
\rho_{\mathrm{post}}
=
\rho_{\mathrm{target}}\frac{\rho(W)}{\rho(W_{\mathrm{orig}})}
<
\rho_{\mathrm{target}}.
\]
Although the weight magnitudes are not changing, the post-normalization spectral radius is. In all three experiments, performance stays flat in these inner fractions. Outside this middle range, the perturbed matrix can have \(\rho(W)>\rho(W_{\mathrm{orig}})\). Scaling by \(\rho(W_{\mathrm{orig}})\) then moves the post-scaling spectral radius back toward, or above, the target value rather than holding it low. The changeover occurs where \(\rho(W)=\rho(W_{\mathrm{orig}})\).

In the \textit{C.\ elegans} sign sweeps, this changeover can occur slightly before the EleganSign-inferred negative-edge fraction rather than exactly at it. The reason is that the sweep does not only change the global fraction of negative edges; it also randomly reassigns which edges carry those signs. The shuffle controls show that randomizing sign placement can itself increase performance and CV, consistent with a reduction in \(\rho_{\mathrm{raw}}\) (Figure~\ref{fig:shuf_all}). A quick comparison of the sign sweeps in the \textit{C.\ elegans} and ER-matched networks is given in Supplemental Figure~\ref{fig:sign_sweep_quicklook}. Therefore, the perturbed \textit{C.\ elegans} matrix can reach \(\rho(W)<\rho(W_{\mathrm{orig}})\) before the sweep reaches the EleganSign-inferred sign fraction. This offset is not expected to appear as strongly in the ER-matched network, where signs are already effectively random with respect to the topology and reshuffling sign placement has little additional effect on the raw spectral radius.

\subsubsection{C. elegans connectome}
This uses the biological network and contact-count weights:
\[
W_{ij}=W^{cel}_{ij}.
\]

\subsubsection{Ambiguous-edge \textit{C.\ elegans} connectome with weight shuffle}
\label{sec:original_weight_shuffle}
Starting from the ambiguous-edge \textit{C.\ elegans} connectome, this architecture preserves the connectome topology but shuffles the weights across existing connections using the weight-shuffle procedure in Section~\ref{Weight-Shuffle}.

\subsubsection{Ambiguous-edge \textit{C.\ elegans} connectome with connection shuffle}
\label{sec:original_connection_shuffle}
Starting from the ambiguous-edge \textit{C.\ elegans} connectome, this architecture applies the degree-preserving connection-shuffle procedure in Section~\ref{Connection-Shuffle}.

\subsubsection{Connection shuffle with weight shuffle}
The \textit{C.\ elegans} connectome is first connection-shuffled as described in Section~\ref{Connection-Shuffle}, and the resulting nonzero weights are then shuffled as described in Section~\ref{Weight-Shuffle}.

\subsubsection[C. elegans architecture with signed unit weights using ambiguous-edge signs]{C. elegans architecture with $\pm 1$ weights using ambiguous-edge signs}
\label{sec:plus1minus1network}
This architecture preserves the ambiguous-edge topology and edge signs while setting every nonzero magnitude to one:
\[
W_{ij}' =
\begin{cases}
\operatorname{sign}(W_{ij}) & \text{if } W_{ij} \neq 0,\\
0 & \text{if } W_{ij} = 0.
\end{cases}
\]

\subsubsection[C. elegans architecture with signed unit weights and shuffled signs preserving sign balance]{C. elegans architecture with $\pm 1$ weights and shuffled signs preserving sign balance}
This control keeps the ambiguous-edge connectivity fixed but randomizes which edges carry inhibitory signs. If
\[
N_-=\#\{(i,j):W'_{ij}=-1\},
\]
then a random subset of size \(N_-\) of nonzero entries is assigned sign \(-1\), and all remaining nonzero entries are assigned sign \(+1\). This preserves the global E/I sign ratio while shuffling sign placement.

\subsubsection[C. elegans architecture with signed unit weights under connection shuffling]{C. elegans architecture with $\pm 1$ weights under connection shuffling}
Starting from the signed unit-magnitude network in Section~\ref{sec:plus1minus1network}, the edge set is connection-shuffled as described in Section~\ref{Connection-Shuffle}.

\subsubsection[C. elegans architecture with signed unit weights under connection and weight shuffling]{C. elegans architecture with $\pm 1$ weights under connection shuffling and weight shuffling}
Starting from the signed unit-magnitude network in Section~\ref{sec:plus1minus1network}, the edge set is connection-shuffled and then the signed unit weights are shuffled across the resulting nonzero entries.

\subsubsection{C. elegans architecture with binary weights}
This ablation preserves the ambiguous-edge connectivity pattern but removes both sign and magnitude heterogeneity:
\[
W_{ij}' =
\begin{cases}
1 & \text{if } W_{ij} \neq 0,\\
0 & \text{if } W_{ij} = 0.
\end{cases}
\]

\subsubsection{C. elegans architecture with binary weights and connection shuffle}
This binary network is rewired with the procedure in Section~\ref{Connection-Shuffle}.

\subsubsection{C.~elegans topology with Gaussian weights}
This control keeps the ambiguous-edge connectivity pattern but replaces each nonzero weight with an independent Gaussian sample:
\[
W'_{ij} =
\begin{cases}
X_{ij} & \text{if } W_{ij} \neq 0,\\
0 & \text{if } W_{ij} = 0,
\end{cases}
\qquad
X_{ij}\sim\mathcal{N}(0,1).
\]

\subsubsection{C.~elegans--matched Erd\H{o}s--R\'enyi model with Gaussian weights}
This random-graph baseline uses \(N=297\) nodes and an adjusted ER edge set with the same number of directed edges as the ambiguous-edge \emph{C.~elegans} network. After fixing the edge count, weights are independently sampled from \(\mathcal{N}(0,1)\).

\subsubsection{Watts--Strogatz Gaussian control}
This small-world control uses \(N=297\) nodes and \(1740\) directed edges. A directed ring lattice is rewired with probability \(p=0.1\), preserving source out-degree and edge count, and nonzero weights are independently sampled from \(\mathcal{N}(0,1)\).

\subsubsection{C. elegans architecture with half Gaussian weights using ambiguous-edge signs}
Starting from the signed unit-magnitude network in Section~\ref{sec:plus1minus1network}, magnitudes are sampled from a half-Gaussian distribution:
\[
W_{ij}'=\operatorname{sign}(W_{ij})|\mathcal{N}(0,1)|.
\]

\subsubsection{C. elegans architecture with uniform weights using ambiguous-edge signs}
Starting from the signed unit-magnitude network in Section~\ref{sec:plus1minus1network}, magnitudes are sampled independently from a uniform distribution:
\[
W_{ij}'=\operatorname{sign}(W_{ij})X_{ij},
\qquad
X_{ij}\sim\mathcal{U}(0,1).
\]
